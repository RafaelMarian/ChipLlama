ChipLlama

Verifiable PIC24FJ256GB110 copilot · Muse Spark + XC16 + register checker

ChipLlama is not a RAG chatbot. It is a closed loop:

  1. Parse the request deterministically (timer, period, Fosc, interrupt) and compute a reference solution with a calculator checked against DS39897C.
  2. Give Muse Spark the register facts and datasheet page images (T1CON/T2CON/T3CON/IFS0/IEC0/IPC pages).
  3. Muse writes C with explicit bit math. A mini register emulator executes the init code and a rule checker compares the final T1CON/PR1/IEC0/IPC0/ISR with the requested period.
  4. xc16-gcc compiles it (skipped gracefully if XC16 is missing). Compiler errors and checker findings are fed back until it verifies.
  5. Export to an MPLAB X-ready folder; optional PICkit 5 flashing via ipecmd is OFF by default.
